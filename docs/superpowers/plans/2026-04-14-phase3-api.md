# Phase 3 — REST API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a fully typed REST API using oapi-codegen strict-server, covering all entity CRUD operations, and mount it alongside the existing web skeleton.

**Architecture:** Write `api/openapi.yaml` as the source of truth; `oapi-codegen` generates the server interface and types into `internal/api/api.gen.go`; `internal/api/handlers.go` implements the interface by calling directly into `internal/store`; the generated router is mounted under `/api/` in `internal/web/server.go`.

**Tech Stack:** Go 1.26, `github.com/oapi-codegen/oapi-codegen/v2`, `database/sql`, `modernc.org/sqlite`, `github.com/stretchr/testify`

---

## File Map

| File | Action | Purpose |
|---|---|---|
| `tools.go` | Create | Pin oapi-codegen to `go.mod` as a tool dependency |
| `oapi-codegen.yaml` | Create | Code-gen config (package, output path, generators) |
| `api/openapi.yaml` | Create | Complete OpenAPI 3.0 spec — source of truth |
| `internal/api/generate.go` | Create | `//go:generate` directive |
| `internal/api/api.gen.go` | Generated | Types + server interface + net/http handler registration — **never hand-edit** |
| `internal/api/handlers.go` | Create | `Handlers` struct implementing `StrictServerInterface` |
| `internal/api/helpers.go` | Create | Mapping functions (model ↔ API type) and entity-name resolver |
| `internal/api/handlers_test.go` | Create | httptest-based tests for every handler |
| `internal/web/server.go` | Modify | Mount generated API router under `/api/` |

```go
	_ "github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen"
```

```bash
go get github.com/oapi-codegen/oapi-codegen/v2/cmd/oapi-codegen
go mod tidy
```

Expected: `go.mod` now lists `github.com/oapi-codegen/oapi-codegen/v2` as a dependency.

- [ ] **Create `oapi-codegen.yaml` at repo root**


- [ ] **Create `internal/api/generate.go`**

```go
// createOrUpdateBlurryDate manages a blurry_date record tied to a parent entity.
//   - input nil, existingID nil  → no-op, returns nil
//   - input nil, existingID set  → deletes the orphaned row, returns nil
//   - input set, existingID nil  → creates a new row, returns its ID
//   - input set, existingID set  → updates the existing row in-place, returns its ID
func createOrUpdateBlurryDate(ctx context.Context, db *sql.DB, input *BlurryDateInput, existingID *string) (*string, error) {
	if input == nil {
		if existingID != nil {
			// Remove the orphaned blurry_date row; ignore not-found in case of double-call.
			if err := store.DeleteBlurryDate(ctx, db, *existingID); err != nil && !errors.Is(err, sql.ErrNoRows) {
				return nil, err
			}
		}
		return nil, nil
	}
	m := blurryDateInputToModel(*input)
	if existingID != nil {
		m.ID = *existingID
		if err := store.UpdateBlurryDate(ctx, db, m); err != nil {
			return nil, err
		}
		return existingID, nil
	}
	created, err := store.CreateBlurryDate(ctx, db, m)
	if err != nil {
		return nil, err
	}
	return &created.ID, nil
}

// ptrString returns nil if s is empty, otherwise a pointer to s.
// Used to normalise optional string fields from request bodies.
func ptrString(s *string) *string {
	if s == nil || *s == "" {
		return nil
	}
	return s
}
```

```go
	b, err := json.Marshal(v)

func do(t *testing.T, h http.Handler, method, path string, body *bytes.Buffer) *httptest.ResponseRecorder {
	t.Helper()
	var req *http.Request
	var err error
	if body != nil {
		req, err = http.NewRequestWithContext(context.Background(), method, path, body)
		req.Header.Set("Content-Type", "application/json")
	} else {
		req, err = http.NewRequestWithContext(context.Background(), method, path, nil)
	}
	require.NoError(t, err)
	rec := httptest.NewRecorder()
	h.ServeHTTP(rec, req)
	return rec
}
```
